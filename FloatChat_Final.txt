## SLIDE 2 — IDEA TITLE & PROPOSED SOLUTION

**Idea Title:** Lehar AI — "Ocean Se Baat Karo": Voice + AI chatbot jo 4000+ Argo floats ka data natural language me accessible banata hai — WhatsApp par, kisi bhi Indian language me

### Proposed Solution
- AI-powered **voice + text conversational interface** jo non-technical users ko ocean data query karne deta hai — **voice in any Indian language** + typed queries in English/Hindi
- User bolta/likhta hai → LLM query ko **SQL + spatial filter** me translate karta hai → Argo database se answer → **3D ocean depth visualization + interactive map + voice explanation**
- **Proactive AnomalyRadar** — system khud alert bhejta hai jab ocean parameters critical threshold cross karein (cyclone precursor, marine heatwave)
- Delivery channel: **Web dashboard + WhatsApp/Telegram bot** — zero app download, zero training

### How it addresses the problem
- Argo data **NetCDF format** me locked hai — sirf domain experts use kar paate hain → hum use SQL + vector DB me convert karke sabke liye kholte hain
- Technical barrier (coding, formats, tools) **completely removed** — voice + chat sab kuch handle karta hai
- Sirf raw data nahi, **meaningful insights + proactive anomaly alerts** deta hai — decision-makers ke liye actionable
- Deploys on **WhatsApp** (500M+ Indian users) — fishermen ko naya app install nahi karna padta

### Innovation & Uniqueness — 5 Named Differentiators (vs Argovis, Euro-Argo, ODV, SAMUDRA)

| Feature | Existing Tools | Lehar AI |
|---|---|---|
| 1. **OceanVoice** — Voice query in Hindi/Tamil/Telugu, voice response | ❌ None offer this | ✅ Web Speech API + Whisper |
| 2. **AnomalyRadar** — Proactive cyclone/heatwave alerts without asking | ❌ All are reactive-only | ✅ Background anomaly engine |
| 3. **WhatsApp/Telegram Bot** — Query ocean data on existing apps | ❌ No interactive bots | ✅ Zero app download delivery |
| 4. **OceanLens 3D** — WebGL 3D depth cross-sections, not flat charts | ❌ All use 2D plots | ✅ Three.js/Deck.gl immersive |
| 5. **Lehar AI Classroom** — Students "adopt" a real Argo float | ❌ No education mode | ✅ NEP 2020 aligned |

## SLIDE 3 — TECHNICAL APPROACH

### Technologies
| Layer | Tech |
|---|---|
| Frontend | React + TypeScript + Tailwind CSS, Recharts + Three.js/Deck.gl (3D), Leaflet interactive maps |
| Voice Engine | Web Speech API (browser-native, free) + OpenAI Whisper fallback |
| Backend | FastAPI (Python) — query engine + LLM orchestration + anomaly detection pipeline |
| Database | PostgreSQL (structured Argo profiles) + FAISS/Chroma (vector DB for RAG metadata search) |
| AI/LLM | Open-source LLM (LLaMA 3 / Mistral via OmniRoute gateway) — NL→SQL + RAG + insight generation |
| Data Pipeline | Python (xarray + netCDF4 + argopy) — NetCDF → cleaned PostgreSQL + Parquet ingestion |
| Delivery | Web App + WhatsApp Business API + Telegram Bot API |
| Security | Read-only SQL execution, input sanitization, Strix autonomous OWASP audit |

## SLIDE 4 — FEASIBILITY AND VIABILITY

### Feasibility Analysis
- **Data 100% available & free** — Argo GDAC + INCOIS open data, no permissions needed; argopy Python library streamlines access
- **All technologies open-source / free-tier** — zero licensing cost (LLaMA/Mistral via OmniRoute, Web Speech API browser-native)
- **Proven pattern** — text-to-SQL + RAG is established architecture; we add domain-specific ocean intelligence layer
- **Team capability** — React + Python + FastAPI stack already configured; prototype achievable in hackathon window
- **INCOIS ecosystem fit** — PFZ advisory already uses WhatsApp/SMS delivery; Lehar AI extends same channel with interactive AI

### Potential Challenges & Risks → Mitigation Strategy
| Challenge | Strategy |
|---|---|
| LLM generates incorrect SQL (hallucination) | Schema-constrained prompting + SQL validation layer + strictly read-only execution |
| NetCDF data volume too large | Indian Ocean subset for PoC; Parquet columnar compression + PostgreSQL indexed queries |
| Ambiguous user voice queries | Clarifying-question loop + query suggestion chips + intent confidence scoring |
| LLM API cost/latency | Open-source models via OmniRoute auto-fallback gateway + cached frequent queries |
| WhatsApp API limits | Rate-limiting + queue system; Telegram as parallel delivery channel |

## SLIDE 5 — IMPACT AND BENEFITS

### Impact on Target Audience
- **Fishermen (1 Crore+ registered with INCOIS):** Voice query in native language on WhatsApp → PFZ-style advisory without literacy barrier or app download
- **Coastal Officers / INCOIS Scientists:** Proactive AnomalyRadar alerts → faster cyclone preparedness & marine heatwave response
- **Researchers / Students:** 3D interactive OceanLens exploration → hours of NetCDF data-wrangling reduced to seconds of conversation
- **Educators / Schools (10 Lakh+ coastal students):** Lehar AI Classroom "Adopt a Float" → live ocean science education aligned with NEP 2020

### Benefits
- **Social:** Ocean data democratization across literacy levels and languages; regional language voice inclusion; experiential science education for coastal schools
- **Economic:** Fuel cost savings for fishermen (INCOIS PFZ saves est. ₹700 Cr/year); zero-cost open-source stack; research productivity 10x gain
- **Environmental:** Early marine heatwave & cyclone precursor detection → climate adaptation acceleration; marine ecosystem health monitoring
- **National:** Direct INCOIS / MoES / Blue Economy Mission alignment; potential to integrate into existing SAMUDRA app ecosystem

### National Adoption Potential
> *"If INCOIS adopts Lehar AI as its public-facing AI layer, 1 Crore+ registered fishermen get interactive ocean intelligence on their existing WhatsApp — no new infrastructure, no training cost, no literacy barrier."*
