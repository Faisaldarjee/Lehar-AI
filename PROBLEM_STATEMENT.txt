# SIH 2026 — Problem Statement

- **Problem Statement ID:** SIH26067
- **Problem Statement Title:** Develop a web-based interactive 3D visualization platform that integrates numerical ocean model outputs and in-situ observations.
- **Theme:** Disaster Management
- **Organization:** Ministry of Earth Sciences (MoES) / INCOIS
- **PS Category:** Software
- **Team Name:** Ctrl Alt Elites

## Description
Develop an advanced web-based interactive 3D platform that integrates numerical ocean model outputs (SST, current vectors, chlorophyll, waves) with in-situ observational datasets (Argo floats, moored buoys) at standardized daily temporal and 0.25° spatial resolution, enabling dynamic exploration of ocean state variables and proactive disaster management across the Arabian Sea and Bay of Bengal.

## Core Features (Approved)
1. OceanVoice — Voice-first interface (Web Speech API + Whisper)
2. AnomalyRadar — Proactive anomaly detection & alert engine
3. WhatsApp/Telegram Bot — Zero app download delivery
4. OceanLens 3D — WebGL depth cross-section visualization
5. FloatChat Classroom — "Adopt a Float" education module

## Tech Stack (Locked)
- Frontend: React + TypeScript + Tailwind CSS + Three.js/Deck.gl + Leaflet
- Backend: FastAPI (Python)
- Database: PostgreSQL + FAISS/Chroma
- AI/LLM: LLaMA/Mistral via OmniRoute + RAG pipeline
- Data Pipeline: xarray + netCDF4 + argopy
- Delivery: Web App + WhatsApp Business API + Telegram Bot
